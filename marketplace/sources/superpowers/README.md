# superpowers

Ten workflow skills from [Superpowers](https://github.com/obra/superpowers)
(v6.3.0, MIT, Jesse Vincent), adapted to Ephe's skill loader.

Included: planning, executing plans, TDD, requesting and receiving code review,
worktrees, finishing a branch, dispatching parallel agents, verification before
completion, and the skill-discipline guide.

Excluded on purpose: the four upstream skills that execute local scripts
(`brainstorming`, `systematic-debugging`, `subagent-driven-development`,
`writing-skills`), every host adapter, the session hook, tests and root
scripts. Ephe's approval gate and tool grants stay authoritative; a skill text
does not grant a tool.

Provenance, the archive hash and the exclusion reasons are in
`PROVENANCE.json`; attribution is in `THIRD_PARTY_NOTICES.md`.
