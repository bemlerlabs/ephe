# Quality Rubric

1. The artifact exists and `verify_artifact` returned `ARTIFACT_VERIFIED` for the returned path.
2. The document has a title, a purpose, ordered sections and a closing section.
3. Every number and proper name traces to the request or a read source; nothing is invented.
4. The source line is present and identical across formats produced from one fact sheet.
5. The measured page or slide count is stated and matches the requested scope.
6. No placeholders, no TODOs, no generic filler.
7. No credential, token or private-key material appears in the artifact or the answer.
8. The QA section reports PASS or FAIL per checklist item.
9. A failed check is reported honestly; an unverified artifact is never called finished.
10. All work stays local; no cloud upload is required.
