# ephe-template-library

Curated, licence-audited local templates for sites, worlds and motion.
The first release ships one MIT website template from a public template
repository, copied verbatim with its `LICENSE` and a recorded sha256.

## What it guarantees

- No runtime network fetch; every shipped file is local.
- Every template has a licence file and a provenance entry.
- A hash mismatch or an unknown id is a refusal, not a silent substitution.
