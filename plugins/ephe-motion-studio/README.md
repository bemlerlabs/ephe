# ephe-motion-studio

Local motion films from HTML, CSS and JS sources. A project is one JSON
document with scenes, a timeline, captions and a brand kit. Sources are
written with a revision conflict check; renders run through the local
Chromium and ffmpeg path and land back in chat as artifacts.

## Commands

- `/motion new`, `/motion open`, `/motion import`, `/motion assets`,
  `/motion brand`, `/motion render`, `/motion templates`.
