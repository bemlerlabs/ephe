# Quality Rubric

1. Strengths/Weaknesses = INTERN und vom Unternehmen kontrollierbar; Opportunities/Threats = EXTERN (Markt, Technologie, Regulatorik, Wettbewerb).
2. Je Quadrant 3–5 Punkte, jeder mit 1 Begründungssatz. Qualität vor Quantität.
3. Ehrlichkeit-Regel: Mindestens 2 unbequeme Punkte (Weakness/Threat) nennen — eine SWOT ohne Schwächen ist wertlos.
4. Kreuz-Kombination abschließen: Welche Stärke nutzt welche Opportunity (SO-Strategie)? Welche Weakness bedroht bei welchem Threat (TT-Risiko)?
5. Quellen für externe Behauptungen via web_search belegen.
6. Ground every number/path on real tool output; no simulated output without a returned path.
