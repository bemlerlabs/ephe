# Quality Rubric

1. Strengths/Weaknesses = INTERNAL and controllable by the company; Opportunities/Threats = EXTERNAL (market, technology, regulation, competition).
2. 3-5 points per quadrant, each with one justifying sentence. Quality over quantity.
3. Honesty rule: name at least 2 uncomfortable points (weakness/threat) - a SWOT without weaknesses is worthless.
4. Complete the cross-combination: which strength uses which opportunity (SO strategy)? Which weakness is threatened by which threat (TT risk)?
5. Support sources for external claims via web_search.
6. Ground every number/path on real tool output; no simulated output without a returned path.
