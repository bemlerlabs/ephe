# Golden Example

## Trace 1 (Standard, text skill - no tool)
1. Input: /email request for a meeting
2. Final: subject (direct, without a tool call).

Quality checklist (covers the rubric fields):
1. Adapt tone to audience and occasion (formal: authority/new client; direct: internal team) - when unsure, ask briefly OR deliver two variants.
2. Structure: subject (concrete, max ~60 chars) -> salutation -> core in the first 2 sentences -> details -> clear call to action with date/deadline -> sign-off.
3. German: use the informal form only when the context clearly calls for it, otherwise the formal form.
4. No filler ("I hereby would like to inform you that..."). Every sentence carries weight.
5. Length: as short as possible, as long as necessary - standard email max ~150 words.
6. Ground every number/path on real tool output; no simulated output without a returned path.
