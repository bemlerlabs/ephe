# Quality Rubric

1. Ton an Zielgruppe und Anlass anpassen (formell: Behörde/Neukunde; direkt: internes Team) — bei Unsicherheit kurz nachfragen ODER zwei Varianten liefern.
2. Struktur: Betreff (konkret, max ~60 Zeichen) → Anrede → Kern in den ersten 2 Sätzen → Details → klarer Call-to-Action mit Datum/Frist → Grußformel.
3. Deutsch: Du-Form nur wenn der Kontext es eindeutig hergibt, sonst Sie-Form.
4. Keine Füllfloskeln ("hiermit möchte ich Ihnen mitteilen, dass..."). Jeder Satz trägt.
5. Länge: so kurz wie möglich, so lang wie nötig — Standard-Mail max ~150 Wörter.
6. Ground every number/path on real tool output; no simulated output without a returned path.
