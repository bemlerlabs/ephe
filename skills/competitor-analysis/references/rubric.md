# Quality Rubric

1. Support EVERY statement about a competitor with web_search and name the source; mark what cannot be supported as "unconfirmed".
2. Separate fact from your assessment.
3. Output the comparison as a create_xlsx matrix or a create_pdf report when asked.
4. Answer in the user's language. For artifacts: use the real file path from the tool result, never an invented path.
5. Do not simulate: never claim a result or a file the tool did not actually return. Ground every claim in real tool output.
6. Ground every number/path on real tool output; no simulated output without a returned path.
