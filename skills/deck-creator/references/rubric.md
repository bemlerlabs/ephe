# Quality Rubric

- The deck must be a real local artifact returned by `create_pitch_deck`.
- The deck must contain a strategic storyline, not a generic document converted into slides.
- Each slide needs one core claim, concise supporting copy, and a visual/proof object.
- The deck should include source notes or assumptions when evidence is not provided.
- The final answer must include the saved path and artifact warnings when validation reports them.
- No fake logos, fake metrics, unsupported traction, placeholders, or "TBD" wording.
