# Quality Rubric

1. Write complete, valid SVG XML.
2. Use the Ephe color scheme: dark green (#22c55e), background (#020504), text (#f0fdf4).
3. Always call create_svg - never send only SVG text in the answer.
4. Briefly explain what the graphic shows.
5. Always set viewBox, always include xmlns="http://www.w3.org/2000/svg".
6. Ground every number/path on real tool output; no simulated output without a returned path.
