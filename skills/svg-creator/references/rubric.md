# Quality Rubric

1. Schreibe vollständigen, validen SVG-XML-Code.
2. Nutze das Ephe-Farbschema: Dunkelgrün (#22c55e), Hintergrund (#020504), Text (#f0fdf4).
3. Rufe IMMER create_svg auf — sende nie nur SVG-Text in die Antwort.
4. Erkläre kurz was die Grafik darstellt.
5. viewBox immer setzen, xmlns="http://www.w3.org/2000/svg" immer angeben.
6. Ground every number/path on real tool output; no simulated output without a returned path.
