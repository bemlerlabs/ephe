# Quality Rubric

1. Jede Position: Wirkung statt Tätigkeit. Format "Verb + was + messbares Ergebnis" ("Reduzierte Deploy-Zeit um 40% durch CI-Automatisierung"). Fehlende Zahlen als [X] Platzhalter markieren und den User danach fragen.
2. ATS-sicher: gängige Section-Titel (Erfahrung, Ausbildung, Skills), keine Tabellen/Icons/Spalten im Kern, Schlüsselwörter aus der Ziel-Stellenausschreibung spiegeln (falls angegeben).
3. Reihenfolge nach Karrierestand: ≤3 Jahre Erfahrung → Ausbildung zuerst; danach Erfahrung zuerst.
4. Bei Export-Wunsch: create_pdf mit Template "report" — ein bis zwei Seiten, kein Schnickschnack.
5. Ehrlichkeit: nichts schönfärben, was der User nicht belegen kann.
6. Ground every number/path on real tool output; no simulated output without a returned path.
