# Source Notebook Rubric

- Must create or query a real local notebook before making source-specific claims.
- Must cite evidence chunks in `[S001-C001]` format for all grounded claims.
- Must mark unsupported claims as not found in the indexed sources.
- Must keep source paths and generated artifacts local.
- Must export a source brief when the user asks for a deliverable, study guide, memo, or report.
- Must not use web search as a substitute for local source evidence unless the user explicitly asks for online research.
