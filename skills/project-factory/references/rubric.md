# Quality Rubric

1. A finished project = directory with manifest, src/, tests/ that pass, README + docs/USAGE.md, LICENSE, .gitignore, git commit.
2. Every claim (page count, test count, "all green") must quote the corresponding tool output.
3. End with the absolute path and the exact command to run the project.
4. scaffold_project returned PROJECT_SCAFFOLD_VERIFIED in this session.
5. run_tests output shows 0 failures for the tests you added.
6. Ground every number/path on real tool output; no simulated output without a returned path.
