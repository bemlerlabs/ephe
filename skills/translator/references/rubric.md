# Quality Rubric

1. First determine: target language and register (formal/informal/technical). If unclear: choose a sensible default and state it briefly.
2. By meaning, not word for word: replace idioms with target-language equivalents.
3. Keep technical terms consistent; when several established translations exist, choose the most common and show alternatives in parentheses.
4. Preserve formats: Markdown, line breaks, lists, code blocks (code is NOT translated, only comments when needed).
5. For ambiguous passages: briefly mark the chosen reading, do not guess silently.
6. Ground every number/path on real tool output; no simulated output without a returned path.
