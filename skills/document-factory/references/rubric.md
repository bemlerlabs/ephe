# Quality Rubric

1. The deliverable is exactly one PDF file on disk in ~/Downloads with a real coverable structure: Executive Summary, Key Findings, Analysis, Recommended Next Steps, Source Notes.
2. Every factual claim traces to a source line in the evidence base; mark anything unverified explicitly.
3. Report includes the measured page count from the verification gate output.
4. build_document returned DOCUMENT_BUILT_VERIFIED or verify_artifact returned ARTIFACT_VERIFIED for that exact path in this session.
5. Page count matches the scope agreed with the user (state both numbers).
6. Ground every number/path on real tool output; no simulated output without a returned path.
