# Quality Rubric

1. Call create_diagram for every mindmap/timeline/roadmap/flowchart/process request.
2. kind richtig wählen: Zusammenhänge rund um ein Thema → mindmap; Zeitverlauf/Meilensteine/Phasen → timeline; Ablauf mit Reihenfolge/Entscheidungen → flowchart.
3. items: 3–9 Punkte, jeder 'Label | Beschreibung'. Labels kurz (max ~40 Zeichen), prägnant, parallel formuliert.
4. Bei Research-Roadmaps: erst web_search, dann belegte Meilensteine/Phasen ableiten.
5. Ein generisches Daten-Diagramm (Balken/Linie/Torte aus Zahlen) gehört zu generate_chart, NICHT hierher.
6. Ground every number/path on real tool output; no simulated output without a returned path.
