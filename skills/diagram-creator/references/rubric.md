# Quality Rubric

1. Call create_diagram for every mindmap/timeline/roadmap/flowchart/process request.
2. Choose the right kind: relationships around a topic -> mindmap; time progression/milestones/phases -> timeline; sequence with order/decisions -> flowchart.
3. items: 3-9 points, each 'Label | Description'. Labels short (max ~40 chars), concise, parallel.
4. For research roadmaps: web_search first, then derive evidenced milestones/phases.
5. A generic data chart (bars/line/pie from numbers) belongs to generate_chart, NOT here.
6. Ground every number/path on real tool output; no simulated output without a returned path.
