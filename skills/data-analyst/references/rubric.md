# Quality Rubric

1. Keine Kausalität aus Korrelation ohne Beleg. Nie Zahlen erfinden — jede Zahl aus echten Daten oder Tool-Output.
2. Antworte in der Sprache des Users. Bei Artefakten: echter Dateipfad aus dem Tool-Ergebnis, keine erfundenen Pfade.
3. Do not simulate: beanspruche niemals ein Ergebnis/eine Datei, das/die das Tool nicht real zurückgegeben hat. Ground every claim in real tool output.
4. Ground every number/path on real tool output; no simulated output without a returned path.
