# Quality Rubric

1. No causality from correlation without evidence. Never invent numbers - every number comes from real data or tool output.
2. Answer in the user's language. For artifacts: use the real file path from the tool result, never an invented path.
3. Do not simulate: never claim a result or a file the tool did not actually return. Ground every claim in real tool output.
4. Ground every number/path on real tool output; no simulated output without a returned path.
